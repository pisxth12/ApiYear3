# 🚀 Laravel API Project (Laravel 11 + Filament 3)

Project នេះគឺជា Backend API System ដែលប្រើ Laravel 11 ជាមួយ Filament 3 សម្រាប់ Admin Panel, PostgreSQL ជា Database និង Docker Sail សម្រាប់ Environment។

---

## 🧱 Tech Stack

- Laravel 11 (REST API Backend)
- Filament 3 (Admin Dashboard)
- Mysql (Database)
- Docker + Laravel Sail (Development Environment)
- WSL2 (Recommended for Windows users)

---

## 📁 Project Features

- RESTful API (CRUD)
- Authentication (Laravel Sanctum or JWT)
- Admin Panel (Filament)
- Database Management (PostgreSQL)
- Dockerized Environment (Sail)
- Clean MVC Architecture

---

## ⚙️ Requirements

Before running the project, make sure you have:

- Docker installed
- WSL2 (recommended for Windows)
- Composer
- Git
